# Multilingual evaluation plan

Create at least 300 labelled queries for each launch language (English, Hindi, Hinglish). Each case records: utterance, detected language, intent, entities, period, expected records, expected answer values, and whether clarification is required.

Core intent fixtures should include expense totals, income totals, outstanding balances, customer outstanding, profit, date ranges, FY/quarter expressions, native numerals, lakh/crore amounts, code-mixing and ambiguous customer names.

Target: >=90% intent accuracy and >=95% answer-value correctness on supported intents. Do not claim these targets are achieved until the labelled evaluation set has been executed.
