# Finova Voice & Tone Guide

Finova copy should be precise, calm, warm and professional. Explain what the product actually did, avoid slang, emojis, inflated claims and vague promises, and distinguish estimates from recorded facts.

| Before | After |
|---|---|
| `Good morning, Shikhar!` | `Good morning, {name}.` |
| `Forecast could not be loaded` | `The cash forecast could not be loaded. Check your access and try again.` |
| `Ask Finova AI` with hype copy | `Ask Finova AI` with a factual description of what the assistant can answer |
| `No data yet` | `No forecast data is available yet. Add a cash account, invoice or expense to build a projection.` |

All new user-facing strings should live in the i18n catalogue and receive English, Hindi and Hinglish values. Hindi and Hinglish wording should be marked for native-speaker review before release.
